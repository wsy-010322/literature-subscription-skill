# Deep Read Report

Generate a detailed Chinese markdown report for a selected paper.

## Required structure

# 文献精读报告：Paper Title

## 1. 基本信息

- Title:
- Authors:
- Year:
- Venue:
- DOI / arXiv:
- Local PDF path:

## 2. 这篇文章想解决什么问题？

Explain the scientific background in detail.

Include:

- the broader research context
- why this problem matters
- what limitations existed in previous work

## 3. 核心思想

Explain the key idea of the paper.

Use clear but technical Chinese.

## 4. 方法细节

Explain the method concretely.

Depending on the paper, include relevant technical details:
- model / framework
- assumptions
- mathematical formulation
- experimental / simulation setup
- compared baselines

## 5. 主要结果

Include concrete results where available:

- quantitative outcomes
- comparison with previous methods
- key findings

If the paper does not provide a number, say so explicitly.

## 6. 局限性和疑问

List limitations, assumptions, or open questions.

## Style

- Write in Chinese.
- Be detailed and technical.
- Do not hallucinate results.
- If a detail is not in the paper, write "文章中未明确说明".
- Do not overclaim.
